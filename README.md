## 🛠 Tech Stack

- **Framework:** React + TypeScript
- **Routing:** React Router
- **Styling:** SCSS Modules
- **State Management:** Local component state (no external libraries)
- **Testing:** Vitest + React Testing Library (basic unit tests)
- **Deployment:** Vercel

---

## 📚 Features

- Pixel-perfect dashboard based on Lendsqr Admin Figma design
- Login simulation using default credentials
- User table with filtering, and pagination
- Dynamic user detail view via routing
- Responsive design across screen sizes
- Modular and scalable folder structure
